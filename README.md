# Kanto Contests

Ruby/Sapphire-style Pokemon Contests, rebuilt for Kanto on gen1recomp.

Talk to the little girl in Celadon City and she'll bring you to the new
Contest Hall. Appeal to the judge in a battle-style contest round.

## v0.1 scope
One COOL contest as a proof of the core loop. The judge's stand-in CLEFAIRY
HP bar is a placeholder for the appeal meter. Coming next: appeal scoring by
move contest category, PokeSnacks and condition, all five contest types,
ranks, and kanto_ribbons ribbons.

## Requires
gen1recomp 0.1.75+.
